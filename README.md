# 🤖 AI Coding Assistant

An AI-powered web application designed to help developers write, understand, debug, and learn programming code.

## ✨ Features

- 💬 AI Chat
- 💻 AI Code Generator
- 🐞 AI Bug Fixer
- 🎨 AI Image Generator
- 📚 Programming Learning Center
- ⚙️ User Settings
- 🔐 Authentication
- 🗄️ MongoDB Database
- 📱 Responsive Web Interface

## 🛠️ Technologies

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- REST API

### Database
- MongoDB
- Mongoose

### Authentication
- JWT
- bcryptjs
